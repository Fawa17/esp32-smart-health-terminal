# 运行手册

这份文档写的是**从零到能看见数据**的完整流程，以及日常改代码、OTA 升级、排故障怎么做。

---

## 0. 系统长什么样

```
        ┌──────────────┐   I2C / ADC / 单总线
        │  ESP32-S3    │──── MPU6050 0x68   计步、跌倒
        │  (RX 固件)   │──── MAX30102 0x57  心率、血氧
        │              │──── CST816S 0x15   触摸
        │              │──── NTC  GPIO4     体温
        │              │──── DS1302 5/6/7   时钟
        │              │──── TK0134 屏      240x296 显示
        └──────┬───────┘
               │ WiFi（手机热点 "ESP"）
               ▼
      mqtt://broker.emqx.io:1883          ← 公网公共 broker，不花钱
        主题 device/my_device_001/data    上行：2 秒一帧
             device/my_device_001/set     下行：改阈值 / 重启 / OTA
               │
               ▼
      ┌──────────────────┐
      │ server.py (3000) │  Python：订阅 MQTT → WebSocket 推给网页
      │  web: index.html │  也提供 /api/history、/api/ai_analysis
      └────────┬─────────┘
               ▼
        浏览器 http://<电脑IP>:3000
```

两个"服务器"别搞混：

| 端口 | 程序 | 干什么 |
|---|---|---|
| **3000** | `server.py` | 数据服务器。不跑它，网页永远显示"离线" |
| **8001** | `python -m http.server` | OTA 文件服务器。只有升级固件时才需要 |

## 1. 一次性准备

### 1.1 ESP-IDF 环境

这份工程用的是 **IDF v5.5.5**，装在 `C:\Espressif`。

`export.ps1` 在这台机器上**不能用**（它按系统 python 3.10 去找不存在的 `idf5.5_py3.10_env`）。
每次开新终端，先跑这一段：

```powershell
$py = 'C:\Espressif\python_env\idf5.5_py3.11_env\Scripts\python.exe'
(& $py 'C:\Espressif\frameworks\esp-idf-v5.5.5\tools\idf_tools.py' export --format key-value) |
    ForEach-Object { if ($_ -match '^([A-Za-z_]+)=(.*)$') { Set-Item "env:$($Matches[1])" $Matches[2] } }
```

建议存成 `C:\ESP32\idf-env.ps1`，以后 `. C:\ESP32\idf-env.ps1` 一行搞定。

### 1.2 Python 虚拟环境

网页服务器和几个脚本**必须用 venv 里的 python**（paho-mqtt / flask-socketio 装在那）：

```
C:\Users\韦兴发\Desktop\smart device\venv\Scripts\python.exe
```

用系统 python 会报 `ModuleNotFoundError: No module named 'flask_socketio'`。

### 1.3 接线

| 外设 | 引脚 | 说明 |
|---|---|---|
| I2C 总线 | SDA=**GPIO8**，SCL=**GPIO9** | 三个器件共用：0x68 / 0x57 / 0x15 |
| MAX30102 中断 | GPIO21 | 不接也能跑（走盲读） |
| NTC | AO=**GPIO4**（ADC1_CH3） | DO 不用接 |
| DS1302 | CLK=5，DAT=6，RST=7 | 三线，需 3.3V + 纽扣电池 |
| 屏幕 | SCK=12，MOSI=11，CS=10，DC=13 | 无 RES 无 BL（8 针模块） |
| 串口 | TX=43，RX=44 | 控制台日志 |
| LED | GPIO48 | 板载 |

## 3. 日常流程 B：启动两个服务、打开网页

```powershell
powershell -ExecutionPolicy Bypass -File 'C:\ESP32\smart device\start_all.ps1'
```

它会做三件事：3000 没起就起 `server.py`、8001 没起就起静态服务器、然后打印访问地址。
用 `pythonw.exe` 启动，所以关掉脚本窗口服务不会停。

手动方式（等价）：

```powershell
# 数据服务器
cd 'C:\Users\韦兴发\Desktop\smart device'
.\venv\Scripts\python.exe server.py

# OTA 文件服务器（另开一个窗口）
cd 'C:\ESP32\smart device\build'
C:\Users\韦兴发\Desktop\smart device\venv\Scripts\python.exe -m http.server 8001
```

打开 `http://127.0.0.1:3000`，手机同 WiFi 打开 `http://<电脑IP>:3000`。

**验收 5 条**：

1. 右上角状态是绿的"在线"，时间在每秒更新
2. 心率/血氧：手指压在 MAX30102 上 15 秒内出数
3. 体温：手捏住 NTC 会往 30 出头爬（这是皮肤温度，正常）
4. 趋势图有曲线，平均值在涨
5. 点设置里的 `+`/`−`，设备侧阈值立刻回执

## 4. 日常流程 C：OTA 升级（不插线）

### 4.1 改版本号

`C:\ESP32\smart device\CMakeLists.txt` 第 4 行附近：

```cmake
set(PROJECT_VER "1.4.5")   # ← 改这里，否则升级完看不出区别
```

### 4.2 编译（**不要烧录**）

```powershell
& $py 'C:\Espressif\frameworks\esp-idf-v5.5.5\tools\idf.py' `
    -C 'C:\ESP32\smart device' -B 'C:\ESP32\smart device\build' build
```

产物：`C:\ESP32\smart device\build\sample_project.bin`

### 4.3 确保 8001 在跑，然后下发指令

```powershell
# 查本机 IP（手机热点通常 172.19.62.x）
Get-NetIPAddress -AddressFamily IPv4 | ? { $_.InterfaceAlias -like '*WLAN*' }

# 推送升级指令（用 venv 的 python，它装了 paho）
& 'C:\Users\韦兴发\Desktop\smart device\venv\Scripts\python.exe' `
    'C:\ESP32\ota_push.py' 'http://172.19.62.149:8001/sample_project.bin' --wait 15
```

或者在网页上点 `设置 → 开始升级`（需要先在 menuconfig 里配好 `OTA → 固件下载地址`）。

### 4.4 该看到的日志

```
I (...) mqtt: 收到 OTA 指令：http://172.19.62.149:8001/sample_project.bin
I (...) ota:  OTA 开始，目标分区 ota_1
I (...) ota:  下载完成，共 1608336 字节
I (...) ota:  校验通过，切换启动分区并重启
        ↓ 重启后
I (...) ota:  运行分区 ota_1，固件 sample_project v1.4.5，状态 PENDING_VERIFY(待确认)
I (...) mqtt: MQTT 已连接
I (...) ota:  已确认当前固件可用，回滚保护解除
```

最后那行 `已确认` 是关键：**60 秒内连上 MQTT 才会确认**，否则自动回滚到上一个固件。
所以新固件如果改坏了 WiFi 配置、起不来，板子会自己退回去，不会变砖。

### 4.5 手动确认/回滚

```powershell
# 强制确认（跳过 60 秒等待）
& $py 'idf.py' -C 'C:\ESP32\smart device' -B build -p COM20 partition-table
```

## 6. 故障排查

### 网页一直"离线"

按顺序查，**90% 是第一条**：

```powershell
# ① 3000 有没有人监听
Get-NetTCPConnection -LocalPort 3000 -State Listen

# ② 设备到底在不在上报（绕过服务器，直接看 broker）
& 'C:\Users\韦兴发\Desktop\smart device\venv\Scripts\python.exe' C:\ESP32\mqtt_watch.py --seconds 10
```

- ① 没监听 → 服务器没起，跑 `start_all.ps1`
- ② 也没数据 → 设备侧问题，看串口有没有 `MQTT 已连接`

### 设备连不上 WiFi

- 热点必须 2.4 GHz（ESP32 不支持 5 GHz）
- 热点名和 `menuconfig` 里一致，注意大小写
- 手机热点开了"AP 隔离"会把设备隔离掉，关掉它

### OTA 卡住 / 下载中断

```
E esp-tls: couldn't get hostname : getaddrinfo() returns 202
```
→ 开机时 DNS 没好就启动了 MQTT。现在的固件已经修了（等拿到 IP 再连），如果还出现说明刷的是老版本。

```
E spi_flash: ... 
E ota: 写入失败
```
→ 分区太小或 flash 有问题，查 `idf.py partition-table` 输出确认 ota_0/ota_1 各 2 MB。

```
W watchdog: 卡死的槽位 #0（任务名 "mpu"）
```
→ 老版本没有 OTA 免检钩子，升级时被看门狗复位。1.0.4 之后已修。

### 屏幕上出现方框

先数数量和比大小：

| 现象 | 原因 | 怎么修 |
|---|---|---|
| 方框个数=中文字数，且**和字号一样大**，整行全是方框 | **字体选错**（该用 `FONT_CJK` 却用了 Montserrat） | 改代码里的字体宏 |
| 方框**和正文一样大**，只有**个别**字方 | 字库里缺这个字 | `node C:\ESP32\fontgen\gen.js` 重新生成 |

### 温度显示 `--`

串口搜 `[Temp]`：

```
W (...) ntc_temp: [Temp] 读取失败，累计 37 次
W (...) ntc_temp: AO 电压异常：0 mV      → 探头没接 / GND 断
W (...) ntc_temp: AO 电压异常：3300 mV   → 探头短路 / VCC 断
```
